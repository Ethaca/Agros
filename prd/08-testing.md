# 08. 테스트

## 현황
**단위 162개 + 시나리오 34개 통과.** 실행: `pnpm test`(둘 다), `pnpm run test:unit`, `pnpm run test:scenarios`. 필요: Node 25+, pnpm, 시나리오는 `demo/*/node_modules`(`npm install`), 컨테이너 테스트는 도커.
테스트마다 시한이 있다(`--test-timeout`). 멈춘 테스트는 실패로 끝난다.

## 단위 테스트 (`test/*.test.ts`)
설정 스키마, **init**(정적 사실 수집·초안 규칙·시험 환경·검증·덮어쓰기 거부·CLI, 29개), report(헤더 해시·변조 거부), pr(브랜치·커밋·복귀·실패 복구), ci, runner(기동·환경 차단·복사본·종료), seed(마커·FK·결정성·마스킹), matrix 규칙, 점검(대조 규칙 포함), secrets(a)(b)(c), scan(종료 코드·`--checks`·타임아웃), fix(제안·적용·거부), 출력 예시(스키마·해시·유출 없음), **container**(샌드박스 실측 10개).
작은 fixture 앱(`test/fixtures/`)과 in-process 가짜 앱으로 만든 것이라 도커·데모 의존성이 없어도 대부분 돈다. 도커가 없으면 컨테이너 테스트는 건너뛴다.

## 시나리오 테스트 (`test/scenarios/`)
A의 **실제 데모 앱**을 임시 복사본으로 만들어 **실제 CLI**로 돌린다. SPEC 10절 인수 기준을 실행 가능한 형태로 고정한 것이다.
| # | 확인하는 것 |
|---|---|
| S1 | 결함 1~5가 맞는 점검에서 🔴, 대조 칸 🟢, 공개 라우트 오탐 0, ⚪ 0 |
| S2 | `realistic-app`은 🔴·🟡·⚪ 0 |
| S3 | `manual-exploit.sh`의 `[VULN]` 번호와 Argos 🔴이 번호 단위로 일치 |
| S4 | `fix`: `--apply` 없이 원본 불변, 적용 후 해당 🔴 소멸, 대조 유지, curl도 `[2,3,5]` |
| S5 | 앱이 안 뜨면 종료 코드 1 + 로그, 결과 파일 없음 |
| S6 | 토큰이 틀리면 로그인이 필요한 리소스는 ⚪/🟡, 🟢·🔴 없음(로그인 없이 새는 `export`만 🔴 유지) |
| S7 | `report`는 🔴이 있어도 0, `block`은 2, 깨끗하면 0 |
| S8 | 같은 설정이면 `matrix.json`·`findings.json`이 바이트 단위로 같음 |
| S9 | 출력 파일·터미널에 마커·비밀·카나리·호스트 경로 없음 |
| S10 | 시연 흐름 소요 시간(scan 0.8초, scan+fix+재scan 3.1초) |
| S11 | `argos report`의 헤더 해시가 파일에서 다시 계산한 값과 일치(인수 기준 3), 결과 파일을 고치면 종료 코드 1 |
| S12 | `examples/out/`이 새 스캔 결과와 일치(시각 제외) |
| S13 | 컨테이너 결과가 프로세스와 바이트 동일, `fix`도 컨테이너에서 동작, 도커 불가는 종료 코드 1, 컨테이너 스캔 시간 |
| S15 | `argos init`: 설정 없는 데모 저장소에서 초안 → 검증 통과(3 페르소나), 수기 설정과 같은 🔴 집합(업무 규칙 하나만 다름), 사람이 확인하면 오탐 소멸, 생성된 설정으로 `ci` 동작, 기본 컨테이너 격리에서 검증, `init-report` 내용 |
| S14 | `argos ci`: 한 명령으로 결과·수정·리포트·PR 본문 생성(원본 불변), `--pr`은 정확히 검증된 패치만 담은 브랜치와 PR(main 불변, 체크아웃 복귀), 종료 코드는 원본 코드 기준, 안전한 앱은 PR 없음, 더러운 저장소는 거부하되 리포트는 남김, 컨테이너 end to end |
S0(init)는 A의 구현 후 추가한다. PR 흐름은 로컬 bare 저장소와 가짜 `gh`로 시험하므로 실제 GitHub에는 아무것도 보내지 않는다.

## 테스트를 쓸 때의 규칙
- "안전"이라는 결론을 내는 테스트에는 **죽은 앱·틀린 토큰 대응 테스트가 짝으로 있어야** 한다.
- 샌드박스 테스트는 **대조 실험**(격리 없음에서는 성공)으로 민감도를 확인한다.
- 예시·문서의 숫자는 실제로 세어서 적는다.
